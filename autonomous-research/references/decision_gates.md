# 决策闸门判据（Decision Gates）

所有闸门为提示词级强制规则：agent 到达判定节点必须显式给出 `闸门结论: PASS / ESCALATE / STOP` 及依据，跳过闸门视为违反协议。

## 1. 算力门槛（Compute Threshold）

**触发条件（任一满足即 ESCALATE）：**
- 单次训练/评估运行预计超过 2 小时（按已有日志或 batch 数 × 单步耗时估算）
- 一次 sweep 的总组合数 > 20（网格或随机搜索的乘积）
- 预计写盘量 > 50 GB
- 显存需求逼近本机上限（4090 = 24GB）需 OOM 风险试错时

**ESCALATE 输出格式：**
```
闸门结论: ESCALATE
预算: 单次 <时长> × <次数> = 总 <时长>, 显存 <GB>, 磁盘 <GB>
依据: <为何需要这么大>
请求: <批准 / 缩减方案A / 缩减方案B>
```
用户批准前不得启动。获批后按批准的**上限**执行，超限自动中止并回报。

## 2. 方向变更（Direction Change）

**以下任一变动必须先请示，禁止自主决定：**
- 更换方法骨干（如 U-Net → Transformer）、更换核心损失范式
- 修改研究问题或假设账本的终极目标
- 增删评估指标、修改主指标定义或比较基线
- 更换数据集主线（消融范围内的子集实验不算）
- 放弃 falsified 的主线假设转向全新方向

**输出格式：**
```
闸门结论: ESCALATE
变更: <从 X 到 Y>
理由: <证伪证据 / 文献依据>
代价: <已投入的沉没成本, 新方向的预算估计>
```

## 3. 结果即停（Result-Stop）

**触发即 STOP，禁止继续调参：**
- 主指标达到实验设计文档中**事前固定**的目标值
- 假设被明确证伪（证伪条件命中）
- 达到设计文档预设的实验次数上限
- 连续 3 轮迭代主指标无显著改善（改善幅度 < 指标自身的测量噪声或 <1% 相对值，取设计文档中的较大者）

STOP 后的两个合法去向：进入 Phase D 归因分析，或进入 Phase E 交接。**不设"再调调看"选项。**

## 4. 自主放行区（无需请示）

以下事项 agent 可自行决定，但必须记录在实验日志：
- 20 组以内的超参微调、batch size / 学习率的常规适配（24GB 显存内）
- bug 修复、环境依赖安装（装到非 C 盘）、数据预处理脚本
- 增加控制变量、补跑缺失的 baseline 复现（单次 <2 小时）
- 假设的措辞精细化（不改变可证伪实质）

## 5. 归因分析模板（连续无改善时强制执行）

```text
数据层: 样本量/分布/噪声是否支撑该假设? → 若否, 建议新假设 H<n+1>
方法层: 假设的前提在该方法上是否成立? → 若否, 该假设对当前方法 falsified
实现层: 是否存在 bug/泄漏/未收敛? → 列证据; 排除后仍无改善回到方法层
```
