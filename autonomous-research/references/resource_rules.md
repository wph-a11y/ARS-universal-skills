# 实验执行与资源规则（Resource Rules）

本机环境：Windows，GPU 为 NVIDIA RTX 4090（24GB 显存）。所有规则为提示词级强制。

## 磁盘纪律（严禁占用 C 盘）

- 项目代码、数据集、模型权重、实验输出、日志一律放工作盘（E: 及其后）
- 环境与缓存重定向：
  - pip：`pip install --cache-dir E:\pipcache ...`
  - conda env：创建到非 C 盘前缀（`conda create -p E:\envs\<name> ...`）
  - HuggingFace/torch 缓存：设 `HF_HOME`、`TORCH_HOME` 指向 E 盘目录
  - 训练脚本内的临时文件、checkpoint 路径显式写 E 盘绝对路径
- 启动长任务前检查目标盘剩余空间 > 预计写盘量 × 1.5

## 执行纪律

1. **启动前自查**（每次运行）：GPU 空闲情况（`nvidia-smi`）、显存预算（模型 + 激活 + 优化器状态 < 22GB）、依赖就绪、输出路径可写
2. **后台运行 + 日志**：长任务后台执行，stdout/stderr 重定向到 `experiments/logs/exp_<id>_<timestamp>.log`，定期查看而非等待卡死
3. **失败处理**：同一命令失败最多重试 2 次；重试前必须读日志定位根因并说明修复了什么。禁止 sleep 等待式轮询，禁止盲目降 batch 反复试 OOM
4. **配置快照**：每次运行前把完整配置（命令行 + 配置文件 + git commit/文件哈希）写入 `exp_<id>_log.md`，保证可复现
5. **结果落盘**：结果文件路径、关键数值（主指标等）当场写入日志，不依赖记忆

## 4090 适配要点

- batch size / 梯度累积按 24GB 上限设计，混合精度（AMP/bf16）优先
- 显存不够时优先顺序：梯度累积 > 梯度检查点 > 减小窗口/分辨率 > 换更小骨干（换骨干触发方向变更闸门）
- 多组实验串行执行，除非单组显存 < 10GB 且已获批准并行

## 日志与实验凭证

实验日志是 Phase E 凭证登记的唯一原始来源，缺失日志的实验不得写入论文。日志最小字段：
`时间戳 | 命令 | 配置快照 | 数据版本 | 随机种子 | 主指标结果 | 结果文件路径 | 异常记录`
